## 2.1 — Список занятий

**Задача.** Использовать три занятия из этапа 1. Показать название и свободные места, поле минимального количества мест и кнопку применения фильтра. Значение по умолчанию — `1`. Переиспользовать правило 1.1, добавить сообщение об отсутствии результатов.

**Сдать:** страницу и короткий чек-лист ручной проверки.

**Приёмка:**
- Видимые подписи связаны с полями, элементы доступны с клавиатуры, фокус заметен.
- При 360 px нет горизонтального скролла; длинное название переносится.
- Пустой результат отличается от ошибки ввода; некорректный фильтр не ломает страницу.
- Ученик показывает, где лежат данные, где строится DOM и какой обработчик вызывает фильтрацию.

**Изменение на защите:** добавить кнопку сброса фильтра и объяснить, почему значение поля и результат должны обновиться вместе.

## 2.2 — Добавить занятие через форму

**Задача.** Расширить страницу формой: название после удаления внешних пробелов длиной 1–80 символов, целое число мест 0–20. Новый id генерируется локально. После успеха добавить занятие, очистить форму и показать подтверждение. Данные только в памяти, после перезагрузки исчезают.

**Сдать:** форму и таблицу проверенных вводов. Сохранить работу фильтра из 2.1.

**Приёмка:**
- Отклоняются пустое/пробельное название, 81 символ, пустое количество, `-1`, `1.5` и `21`.
- Значения `0` и `20` принимаются; числовое поле явно преобразуется и проверяется.
- При ошибке введённое не теряется, сообщение находится рядом с полем; Enter отправляет форму без перезагрузки страницы.
- Одна отправка создаёт одну запись; новый результат подчиняется действующему фильтру.

**Изменение на защите:** изменить верхнюю границу мест на `12`, обновить сообщение и проверки граничных значений.

## 2.3 — Чужой обработчик и безопасный текст

**Задача.** Разобрать намеренно проблемный фрагмент. Контракт: кнопка увеличивает значение на единицу при каждом клике, название показывается буквальным текстом.

```js
const input = document.querySelector('#places');
document.querySelector('#increase').addEventListener('click', () => {
  input.value = input.value + 1;
});
document.querySelector('#preview').innerHTML =
  document.querySelector('#title').value;
```

Создать минимальную HTML-страницу с этими id и кнопкой `type="button"`. Прогнозировать поведение для `2`, пустой строки и названия `<b>Шахматы</b>`. Исправить: пустое/нечисловое/дробное значение выдаёт ошибку, целое 0–19 увеличивается, 20 не увеличивается. Название не интерпретируется как HTML.

**Сдать:** исправление, результаты воспроизведения и описание DOM API, выбранного для вывода текста.

**Приёмка:**
- После `2` получается `3`, после двух кликов — `4`; проверена граница 20.
- Строка с тегами видна буквально, новый HTML-элемент из неё не создаётся.
- Ученик объясняет разницу строки и числа, а также текста и HTML.

**Изменение на защите:** перенести те же правила в предпросмотр формы 2.2 без дублирования правил в нескольких обработчиках.
