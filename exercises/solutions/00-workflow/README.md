# Задание 0.2

Версия Node.js: `v22.16.0`

- Команда запуска `hello.mjs`: `node exercises/solutions/00-workflow/hello.mjs`;
- Команда запуска `debug.mjs`: `node exercises/solutions/00-workflow/debug.mjs`;

- Ожидал: после исправления — 3;
- Получил: сначала ReferenceError, затем 3;
- Причина: использовалось имя freePlace, хотя объявлено freePlaces;
- Исходная ошибка: `ReferenceError: freePlace is not defined`;
- Выполнение остановилось, потому что JavaScript не нашёл переменную `freePlace` и не смог вычислить выражение.
- Проверка: после исправления, повторный запуск вывел 3.
- Проверка в браузерной консоли: `freePlaces + 1` вернуло `3`.
- Изменение на защите: число `2` временно изменено на `5`, результатом стало `6`; затем исходное значение восстановлено.
