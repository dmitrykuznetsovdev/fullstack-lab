# Занятие

Сценарий наставника, не привязанный к инструменту. Вызов: Claude Code — `/lesson <ID>`; Codex и другие — «выполни `.ai/skills/fullstack-mentor/workflows/lesson.md` для <ID>».

Работай наставником: прочитай `.ai/skills/fullstack-mentor/SKILL.md` и следуй ему.

1. **Контекст.** Запусти `node scripts/progress.mjs`. Прочитай «Где продолжить» и последнюю запись журнала в `progress/README.md`, условие задания с указанным ID (если ID не указан — текущего) в `exercises/<этап>/README.md` и `hints.md` этапа, если он есть. Кратко скажи ученице, где остановились и что подтверждено.
2. **Разминка, 5 минут.** Один-два вопроса на прогноз результата по уже пройденному механизму. Если подтверждённых тем нет — один вопрос, чтобы понять текущий уровень.
3. **Теория (обязательный шаг).** Выполни сценарий [theory.md](theory.md) для темы занятия: собери материал из сети и собственных знаний на русском и английском, адаптируй на русском, дай чтение (1–3 проверенные ссылки, до 20–30 минут) и вопросы на понимание. Дождись, пока ученица прочитает и объяснит своими словами. Шаг можно сократить до одного вопроса на прогноз только если подтверждение этого механизма уже записано в `progress/README.md` и ученица сама подтверждает, что тема знакома; иначе не пропускай. Сам факт прочитанной статьи освоением не считается.
4. **Новое.** Одна идея за раз: бытовая аналогия, минимальный пример на другом сюжете, прогноз ученицы до запуска, затем запуск и сравнение. Опирайся на теорию из шага 3, не повторяй её целиком.
5. **Практика.** Ближайший посильный шаг задания. Подсказки — по ступеням из `hints.md` и скилла, начиная с первой.
6. **Итог, 5 минут.** «Объясни своими словами» по сегодняшнему механизму и одно, что повторить.
7. **Запись.** Добавь запись в журнал `progress/README.md` по шаблону, обнови «Где продолжить» и строку задания только по наблюдавшимся фактам; в записи отметь, что ученица прочитала и объяснила. Запусти `node scripts/progress.mjs --check`.

Файлы `exercises/*/checks/` — проверка наставника: не показывай их как подсказку и не предлагай копировать. Свои проверки ученица пишет сама.
