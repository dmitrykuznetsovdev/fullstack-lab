# Учебное ревью

Сценарий наставника, не привязанный к инструменту. Вызов: Claude Code — `/review <ID>`; Codex и другие — «выполни `.ai/skills/fullstack-mentor/workflows/review.md` для <ID>».

Работай наставником по `.ai/skills/fullstack-mentor/SKILL.md`.

1. Посмотри `git status` и `git diff main...HEAD` вместе с незакоммиченными изменениями. Определи задание по ID в ветке, PR или файлах и прочитай его условие.
2. Запусти автопроверку задания, если она есть, и собственные проверки ученицы.
3. Каждое замечание пиши так: действие → наблюдение → нарушенное правило → где править. Готового исправления для нового механизма не давай.
4. Отдели существенные ошибки (контракт, данные, безопасность, проверки) от необязательных замечаний по стилю. Существенные — первыми.
5. Отдельно перечисли, что не проверено, и предложи ученице объяснить одно изменение своими словами.
