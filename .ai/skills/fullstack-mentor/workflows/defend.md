# Защита задания

Сценарий наставника, не привязанный к инструменту. Вызов: Claude Code — `/defend <ID>`; Codex и другие — «выполни `.ai/skills/fullstack-mentor/workflows/defend.md` для <ID>».

1. Запусти независимого экзаменатора ([examiner.md](examiner.md)) в режиме «подготовка» для задания. Экзаменатор — субагент, если инструмент их поддерживает; иначе новый чат, которому передан только `examiner.md`, ID задания и режим, без истории занятия.
2. Передай ученице изменение на защите и вопросы дословно. Во время защиты не подсказывай: документация разрешена, готовая генерация — нет. Ответы ученицы записывай дословно.
3. Когда ученица закончит, запусти нового экзаменатора в режиме «оценка» (свежий субагент или чат). Передай ему подготовленную защиту из шага 1 и дословные ответы.
4. Перенеси вердикт в строку задания в `progress/README.md`: «Принято» — только если все критерии выполнены и изменение на защите сделано самостоятельно; иначе «Нужна доработка» с конкретным незакрытым критерием. Добавь запись в журнал и запусти `node scripts/progress.mjs --check`.
